Настройки
Для обычной работы заходить сюда не нужно. Здесь можно подключить другой браузер или сохранить данные отдельным файлом.
Без подключения облака данные остаются только в этом браузере.
Подключить облако
«Ссылка для другого браузера» подключает телефон или компьютер к той же базе. Ссылка секретная — передавайте её только себе. «Отключить облако» отключает только этот браузер, не удаляя базу.
Резервная копия — необязательный файл со всеми персонажами, текстами и отметками. Для синхронизации она не нужна. «Восстановить копию» заменяет текущие данные содержимым файла; используйте только при необходимости. Секретного ключа в копии нет.
