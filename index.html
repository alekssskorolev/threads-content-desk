Суммы последних записанных счётчиков исходных постов, не уникальная аудитория. Пусто = неизвестно, 0 = измеренный ноль. Возраст постов может различаться. Переходы требуют отдельного источника отслеживания ссылок.
Отметки и статистика сохраняются только в этом браузере. Резервная копия нужна для переноса на другое устройство и защиты от очистки браузера. Нет облачной синхронизации и автопубликации.

Подключение парсера

Можно выбрать один или несколько файлов archive.json из вашего Threads Collector (links-v2) либо готовую выгрузку threads-metrics. Они обрабатываются локально в браузере, без отправки на сервер. Сам сайт не заходит в Threads и не запускает парсер по расписанию.

  1. Опубликуйте пост и сохраните его ссылку в карточке.
  2. Парсер должен возвращать точную ссылку, время измерения и счётчики исходного поста.
  3. Нажмите «Импорт из Collector» и выберите archive.json. Архив обычно лежит в ~/Library/Application Support/Threads Collector/data/output/USERNAME/links-v2/. При сборе включите «Обновить статистику», иначе счётчики могут остаться старыми. Совпадение идёт по ID поста из ссылки, не по похожему тексту.
{"kind":"threads-metrics","version":1,"observations":[
 {"url":"https://www.threads.com/@handle/post/POST_ID",
  "observed_at":"2026-10-24T12:00:00Z",
  "views":1200,"likes":24,"replies":3,"reposts":2,
  "quotes":0,"shares":null,"clicks":null,"source":"my-parser"}
]}

Неизвестные значения пропускайте или передавайте null. Не подменяйте их нулями. Поля — целые неотрицательные числа. Переходы добавляйте только при наличии отдельного источника.

Для ежедневного обновления нужен запуск парсера вне браузера и хранилище результатов. Не помещайте пароли, cookies или API-токены в публичный репозиторий.
