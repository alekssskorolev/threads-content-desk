Одни отметки во всех браузерах

Подключите созданную базу Яндекс Cloud. Сначала будет проверен ключ, затем на сайте можно перенести старые отметки.

Не отправляйте ключ и приватную ссылку в чат. Ключ хранится в этом браузере и не включается в резервные копии.

Подключить через файл конфигурации

Если вы скачали client-config.json из своего Cloud Shell, выберите его здесь. Исходный файл никуда не загружается; его ключ используется только для запроса к указанной выше функции.

В новом браузере также нужно один раз выполнить подключение. Это не вход в Яндекс: пароль от аккаунта здесь не нужен.
